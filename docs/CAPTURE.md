# 原生截图工具

通过 ⌘⇧4、搜索「截图」或菜单栏开始捕获。默认绑定若与系统截屏冲突，Oil Find 保留期望值并在设置 → 截图显示注册状态；按提示到键盘 → 键盘快捷键 → 截屏关闭相同的系统绑定后返回重试。应用不修改系统偏好，⌘Space 搜索继续独立注册。屏幕录制权限仅在用户执行捕获时请求；拒绝时停止捕获，设置提供入口和重试。

拖动选择区域，Space 在选窗与选区之间切换（长按不连续切换），Esc 取消。普通选区或选窗在松开鼠标后保留待确认的区域：点击「确认截图」或按 Return 捕获；点击「重新选区」、按 R 或在待确认区域上重新拖动，会清除原框并返回区域绘制；切到选窗后也可按 R 返回区域绘制，或再按 Space 切回选区。确认前不采集屏幕像素。编辑器中的「重新选区」开始新的截图，保留原文档及尚未保存的标注；取消重选可继续原来的编辑。全屏捕获鼠标所在显示器；跨屏区域按参与显示器的最高缩放比例合成，屏幕空隙透明。ScreenCaptureKit 过滤整个 Oil Find 应用，避免把选区蒙层、编辑器、工具条及钉图窗口加入成品。普通捕获后打开编辑器，取消不会改写剪贴板或生成历史。

**⌃⇧⌘4**、搜索「直接截图」或对应菜单项走直接复制路径：松开鼠标后将选区或窗口的 PNG 写入剪贴板，不打开编辑器、不自动向磁盘导出明文图片。图片复制成功后才保存独立截图历史；原剪贴板的开启、暂停、来源排除及容量限制仍生效。取消、权限拒绝、捕获失败和过期回调不改写剪贴板或生成历史。两种截图快捷键具有独立偏好、Carbon 事件 ID、录制、恢复默认和注册状态；若系统仍占用直接复制快捷键，设置显示具体冲突并提供同一截屏设置入口，由用户关闭对应系统绑定。

选区蒙层使用可接收键盘及首次点击的非激活面板，不依赖 Oil Find 成为前台应用。Space、R、Return 和 Esc 在蒙层及其按钮获得焦点时均由当前捕获会话处理；没有窗口信息的按键按当前键盘焦点投递，原生取消响应也可关闭蒙层。在不同显示器的蒙层之间切换焦点继续选区；切到其他窗口或应用则取消未确认的捕获，避免留下无法操作的选框。非激活面板保留原应用的前台状态，因此工作区激活通知只在实际前台进程发生变化时取消；原应用的重复激活和晚到通知不会丢弃已选择的窗口。普通截图点击窗口后仍按 Return 或点「确认截图」进入编辑器，直接复制路径单击后写入剪贴板。关闭时移除键盘监听和焦点观察，取消不夺回其他应用的焦点，不申请额外键盘监听权限。

长截图先选区域，再手动向下滚动。每秒最多 8 个帧的屏幕流仅在该会话运行；连续稳定帧才进入重叠匹配，候选须通过每行验证且唯一。固定页眉页脚保留一份。滚动过快、重复内容、动态内容、反向滚动或尺寸变化无法可靠匹配时保留已拼接内容并提示调整；达到容量停止流，可结束并编辑已有内容。长截图区域须位于一个显示器内。工具不向其他应用发送滚动事件，无需额外辅助功能权限。

编辑器支持多个文档的原生窗口标签，缩放、选择、Shift 多选、移动、右下角调整大小、撤销和重做。工具包括箭头、直线、矩形、椭圆、步骤、文字、画笔、高亮、马赛克、实色遮挡、裁剪、Emoji 与本地导入贴纸。文字、颜色、线宽和字号可调整。菜单可复制或删除所选对象，保存所选对象为素材，再插入其他文档；素材不附带底层截图。

复制、保存或钉住成品后才写入独立截图历史。保存面板默认 PNG，也可选择 JPEG，记住上次目录，不自动向桌面保存。原图、裁剪范围和原图像素坐标中的标注分别保存，重新打开历史可继续编辑。导出时在新像素画布上合并全部标注，不附带原图、编辑图层或原文件元数据。**可编辑历史会保留打码前原图**，需要彻底移除时删除对应历史并清空其他原图副本。

截图历史默认 7 天、100 张、总计 256 MiB，设置支持关闭记录、1–365 天、1–1,000 张和清空。每个文档最多 6,400 万像素，单边 32,768 像素，原图与资源合计最多 64 MiB。超限时保留当前编辑，提示裁剪或降低分辨率。捕获结果的无损编码过大时，保留已捕获图像并让用户选择以 50% 分辨率继续编辑；取消才丢弃本次捕获。剪贴板政策独立保持原有规则：图片最多 16 MiB、总历史 32 MiB。大成品可复制或导出，但不会进入剪贴板历史；开启、暂停及来源排除仍生效。自身写入使用标记避免重复采集。

截图历史和素材均由 AES-GCM 加密。经现有 `ClipboardKeyProviding` 取得主密钥，只在内存通过独立 HKDF 用途派生密钥。复用固定 XPC 密钥服务，不新增钥匙串项目，不改服务、证书或访问规则。存档目录 0700，文件 0600；随机 UUID 文件承载加密原图和标注，加密索引仅保存元数据。新版本文件写入完成、加密索引原子提交成功后，才清理旧文件。历史按需读取，缩略图只在可见行解码；无法读取的旧索引或文档受到保护，保存错误不会以替代密钥覆盖原档。编辑内容留在窗口中供复制或导出。

OCR 只在点击「识字」后后台调用 Vision，识别中文和英文并自动检测语言。识别结果可以修订、选择及复制，不联网，不写入文件索引；仅复制 OCR 文本不保存整张截图。钉图文可来自截图、图片或剪贴板文本，支持拖动、缩放、透明度、复制及当前或所有桌面；退出后不自动恢复私人内容。

自动维护须同时核对剪贴板与截图历史的保存状态、待保存任务和未保存编辑。安装前备份应用、偏好、剪贴板密文、截图及素材目录；保持固定证书和逐字节复用 XPC 缓存。密钥、签名或缓存异常时保留旧应用，不能重建服务或替换密钥。首次屏幕录制授权和系统截屏快捷键调整由用户本人操作。macOS 14/15 的兼容路径由自动化覆盖，真机验收需另行记录。
